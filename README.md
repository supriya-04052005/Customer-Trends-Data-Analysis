# 👩🏻‍💻 Customer Trends Data Analysis | SQL, Python & Power BI

## 📌 Project Overview

This project explores customer shopping behavior using an end-to-end data analytics workflow. It demonstrates how raw customer data can be prepared, analyzed, and visualized to identify purchasing patterns and generate business insights.

The project covers data preparation, exploratory data analysis, SQL-based business analysis, Power BI visualization, and project documentation.

**Purpose:** This repository is part of my learning journey as an aspiring Data Analyst. It is based on the original project by [Amlan Mohanty](https://github.com/amlanmohanty1/customer-trends-data-analysis-SQL-Python-PowerBI), which I am using as a reference to learn practical data analytics workflows.

## 🎯 Project Objectives

- Understand customer shopping and purchasing behavior.
- Explore and clean customer shopping data using Python.
- Analyze customer and product trends using SQL.
- Identify patterns that can help answer business questions.
- Visualize relevant metrics and trends using Power BI.
- Learn how to communicate analytical findings and business recommendations.

## 🛠️ Tools and Technologies

- **Python** – Data analysis and exploratory data analysis.
- **Pandas** – Data manipulation and cleaning.
- **Jupyter Notebook** – Executing and documenting Python analysis.
- **SQL** – Querying data and answering business questions.
- **PostgreSQL / MySQL / SQL Server** – Database options, depending on the configuration used.
- **Power BI** – Interactive dashboards and data visualization.
- **CSV** – Structured dataset storage and exchange.

## 🔄 Project Workflow

### 1. Data Preparation and Exploratory Data Analysis

- Import the customer shopping dataset.
- Inspect the dataset structure and data types.
- Identify missing values and duplicate records.
- Clean and prepare the data for analysis.
- Explore customer and purchasing patterns.

### 2. SQL Data Analysis

- Load the prepared dataset into a SQL database.
- Write SQL queries to answer business-related questions.
- Analyze purchasing patterns, customer segments, and product trends.
- Summarize findings that may support business decisions.

### 3. Power BI Dashboard

- Connect the database or prepared dataset to Power BI.
- Create visualizations for relevant customer and shopping metrics.
- Explore patterns and trends through charts and dashboard interactions.

### 4. Reporting and Documentation

- Document the analysis workflow.
- Summarize verified findings.
- Identify potential business recommendations based on the analysis.
